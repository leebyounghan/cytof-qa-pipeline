# GPT-6 Luna medium flat experiments (2026-10-29)

## Design

- Methods: flat cascade and flat C2S FlowSOM, both using `gpt-6-luna`, API reasoning effort `medium`, temperature 1.0, and 32768 maximum completion tokens.
- Scope: `test` split. Eight non-Acute/Vaccine cohorts use their full gating trees. Acute2020, Acute2021, and Vaccine use the shared L1 coarse, L2 identity, and L3 full plans.
- Plan files for the three Acute/Vaccine cohorts are under `benchmark_flat/<cohort>/`. The corresponding L1, L2, and L3 files are byte-identical across the three cohorts. The L3 file has no `note` or `tips` fields.
- Flat C2S FlowSOM uses a 10×10 SOM. Its metacluster count is the gating plan leaf count: 16 at L1, 38 at L2, and 83 at L3. Per-sample `c2s.json` and other preparation files live under `benchmark_flat/`; depth-specific acute preparations live under `benchmark_flat/by_plan/<plan_slug>/`.
- Prediction roots: `results/flat_cascade_gpt-6-luna-medium/` and `results/flat_c2s_flowsom_gpt-6-luna-medium/`. Plan slugs are `L1_coarse`, `L2_identity`, and `default` (L3/full).
- Cascade inference accounting: each sample has `inference_calls.jsonl` with one row per API attempt (UTC start, API elapsed seconds, response ID, token usage including cache/reasoning, and estimated USD). Each successful step also embeds its inference row in `step_NN/prediction.json`; `cascade_meta.json` contains per-sample totals. Only API call time is counted, excluding data preparation and evaluation. The cost is an estimate from `src/llm_gate_flat/pricing.json`, whose GPT-6 Luna rates match the existing `jobs/estimate_cascade_api_cost.sh`; it is not an invoice.
